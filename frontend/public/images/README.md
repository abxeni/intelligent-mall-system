# Dashboard images

Place general dashboard images in this directory and brand logos in `logos/`.
Files in `frontend/public/` are served from the site root, so use paths such as
`/images/store-interior.jpg` and `/images/logos/mall-logo.svg` in the frontend.

The dashboard currently uses `CortexMallText.png` for the account picker,
`brainImage.png` in the overview intelligence hub, and
`logos/cortexMallLogo.png` for the sidebar brand and browser icon.
